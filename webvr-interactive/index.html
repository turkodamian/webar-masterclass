Masterclass · WebVR / 3D interactivo

Un mundo 3D en tu navegador

Seis estaciones, seis formas distintas de interactuar. Apuntá el retículo del centro a un objeto y tocá / clic para activarlo. Caminá para descubrir la estación de proximidad.

Desktop: arrastrá para mirar · WASD para moverte · clic Móvil: movés el celu para mirar · tocá Headset: botón VR (abajo a la derecha)

Tipos de interacción

  • Clic / activación — cubo: cambia de color
  • Hover / mirada — esfera: se agranda al apuntarla
  • Animación por evento — toroide: gira al tocarlo
  • Spawn / instanciar — cono: crea objetos que caen
  • Estado / toggle — cilindro: prende/apaga la luz
  • Manipulación / agarrar — icosaedro: clic para tomar/soltar
  • Proximidad — obelisco al fondo: reacciona al acercarte
